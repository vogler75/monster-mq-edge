MonsterMQ Edge REST API

The API runs on the GraphQL listener. Use Basic authentication or an edge session token from POST /api/v1/login. Download OpenAPI YAML.

MethodPathPurpose
POST/api/v1/loginGet a session token
POST, PUT/api/v1/topics/{topic}Publish bytes or a query payload
GET/api/v1/topics/{topic}?retainedRead retained value
GET/api/v1/topics/{topic}Read current value from Default
GET/api/v1/topics/{topic}?rawRead original bytes from one topic
GET/api/v1/topics/{topic}?start=...Read history from Default
POST/api/v1/writeBulk publish
POST/api/v1/write/influxInflux line protocol
GET/api/v1/subscribe?topic=...Server-Sent Events

Omitting group or sending ?group= selects Default. Set ?group=Name to read another archive group.

curl 'http://localhost:4000/api/v1/topics/sensor/temperature'

Read multiple topics

The topic path accepts one MQTT filter. Encode + as %2B to match one level, or # as %23 to match all remaining levels. The result is a JSON messages array. For unrelated filters, make separate GET requests; the SSE endpoint accepts repeated topic parameters.

curl 'http://localhost:4000/api/v1/topics/cameras/%23'
curl 'http://localhost:4000/api/v1/topics/cameras/%2B/snapshot'

Read original bytes

Add ?raw to a GET for one exact topic to receive the original MQTT payload, with no JSON or base64 wrapper. This works for current values and retained messages. Recognized image payloads are served with an image content type; other payloads use application/octet-stream. Raw reads of wildcard filters or history return HTTP 400, and a missing topic returns HTTP 404.

curl -o snapshot.jpg 'http://localhost:4000/api/v1/topics/cameras/front/snapshot?raw'
curl -o snapshot.jpg 'http://localhost:4000/api/v1/topics/cameras/front/snapshot?retained&raw'

The default archive group stores current values in memory and does not keep history unless configured with an archive store. Request bodies are limited to 4 MiB.
